# 文档生成标准（精度层）

> 通用规范；项目可提供自己的模糊词表与上限。参考实现：`scripts/doc_check.py`。适用于任务书渲染、设计文档、事故复盘、发布说明。
> 核心：骨架固定、每节有用途与上限、事实/判断/待定分区、机器可查优先。

## 1 通用规则
- 开头先声明文档类型与读者；类型不同，骨架不同，不许混写。
- 骨架固定，不随意增删节；确需新增，先改本标准。
- 每节写一句用途；没有内容就删节或写“无”，不留空标题。
- 事实、判断、待定问题分开放；待定问题只在末尾集中出现。
- 每条 bullet 只写一个主张；数字必须带来源或可复现命令。
- 禁用模糊词：大概、可能、建议考虑、应该没问题、尽量、适当、酌情。
- 不重复结论，不写“背景介绍”除非它影响决策。
- 长度上限：任务书渲染 ≤80 行；设计文档 ≤150 行；事故复盘 ≤100 行；发布说明 ≤60 行。

## 2 任务书（JSON 渲染视图）
骨架：标题 / 目标 / 范围（允许+禁止）/ 不变量 / 验收（命令+期望）/ 依赖与风险 / 停止条件 / 检查点 / 未决问题。
- 目标：一句话，可验证；不写“优化/完善/提升”。
- 范围：allow 与 deny 都列；路径到文件或目录前缀。
- 不变量：≤5 条，写“不可破坏什么”，不写实现步骤。
- 验收：每条含 `cmd` 与 `expect`；expect 只能是 exit 0、empty、>= N。
- 风险：≤5 条，每条带应对；没有就写“无”。
- 未决问题：每条含 owner 与截止时间；没有写“无”。

## 3 设计文档
骨架：
1. 问题与目标（≤3 句）
2. 非目标（明确不做什么）
3. 现状与约束（代码/契约/环境事实，带路径或命令）
4. 方案（至少一个备选，写清为什么否决）
5. 影响面（API / schema / 令牌 / 兼容性 / 发布）
6. 验证与验收（命令 + 期望）
7. 风险与回滚（触发条件 + 回退动作）
8. 未决问题（owner + 截止）
规则：方案节没有备选与否决理由 = 不合格；影响面漏契约 = 不合格；未决问题不得用“后续再看”代替 owner。

## 4 事故复盘
骨架：
1. 时间线（带时区，关键节点附证据：提交/日志/截图）
2. 影响（用户、数据、版本、持续时间）
3. 直接原因（触发动作）
4. 根因（流程、门禁、认知，三者至少归一类）
5. 处置（止血与恢复）
6. 防复发（每条可验证，含 owner 与期限）
7. 未决问题
规则：根因不得写“粗心/疏忽”；防复发必须能落到 gate、测试或检查脚本，否则视为口号。

## 5 发布说明
骨架：用户可见变更 / 修复 / 破坏性变更与升级步骤 / 已知问题。
规则：面向用户，不写内部重构细节；breaking 必须给迁移步骤；已知问题必须给规避方式。

## 6 Lint 目标（Phase 2 实现）
命令：`doc check <file> --type task|design|incident|release`。
检查项：类型与骨架、必备节、空节、行数上限、模糊词、验收命令格式、未决问题 owner、重复标题。
输出沿用 task CLI 信封：`{ok, errors:[{path, code, message}], warnings}`；exit 0/1/2。

机器可查 vs 人审：
- 机器：结构、长度、模糊词、命令存在、待定分区。
- 人审：方案是否合理、根因是否到位、验收是否充分。

## 7 生成流程
1. 先填结构化字段（任务书 JSON；设计文档先列提纲字段）。
2. 用固定模板 render。
3. 跑 `doc check`。
4. 人审判断性内容。
禁止跳过 1–3 直接自由写正文；自由写只允许出现在 `notes`，且受行数上限约束。

## 8 用例
| 编号 | 场景 | 期望 |
|---|---|---|
| D01 | 设计文档缺“非目标” | exit 1，`SECTION_MISSING` |
| D02 | 存在空节 | exit 1，`SECTION_EMPTY` |
| D03 | 超过行数上限 | exit 1，`TOO_LONG` |
| D04 | 含“大概/可能” | exit 1，`VAGUE_WORD` |
| D05 | 方案无备选与否决理由 | exit 1，`NO_ALTERNATIVE` |
| D06 | 事故根因写“粗心” | warning，`ROOT_CAUSE_WEAK` |
| D07 | 发布说明 breaking 无升级步骤 | exit 1，`MIGRATION_MISSING` |
| D08 | 未决问题无 owner | exit 1，`OPEN_QUESTION_NO_OWNER` |
| D09 | 合规设计文档 | exit 0 |
| D10 | 任务书 JSON 渲染 | exit 0，行数 ≤80 |
